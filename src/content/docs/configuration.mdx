## Server Configuration

```json title="config/cobblenav/server-config.json"
{
  "hideUnknownPokemon": false,
  "hideConditionsOfUnknownSpawns": true,
  "hideNaturalBlockConditions": true,

  "syncEvYieldWithClient": true,

  "searchAreaHeight": 128.0,
  "pokemonFeatureWeights": {
```

### hideUnknownPokemon

Determines whether Pokémon that the player has not discovered yet are hidden from the PokéNav.

* **Type**: `boolean`
* **Default**: `false`

### hideConditionsOfUnknownSpawns

Determines whether spawn conditions are hidden for Pokémon that the player has not discovered yet.

* **Type**: `boolean`
* **Default**: `true`

### hideNaturalBlockConditions

Determines whether blocks tagged as natural are excluded from block-based spawn conditions.

* **Type**: `boolean`
* **Default**: `true`

### percentageForKnownHerd

Determines the percentage of a herd that must be known to the player before the herd's Pokémon information is displayed.

* **Type**: `float`
* **Default**: `0.5`

### syncLabelsWithClient

Determines whether Pokémon labels are synchronized from the server to the client.

* **Type**: `boolean`
* **Default**: `true`

### syncEvYieldWithClient

Determines whether Pokémon EV yield information is synchronized from the server to the client.

* **Type**: `boolean`
* **Default**: `true`

### searchAreaWidth

Sets the horizontal range used when searching for Pokémon through the PokéFinder.

* **Type**: `float`
* **Default**: `128.0`

### searchAreaHeight

Sets the vertical range used when searching for Pokémon through the PokéFinder.

* **Type**: `float`
* **Default**: `128.0`

### pokemonFeatureWeights

Defines the weights used by the PokéFinder when evaluating Pokémon features. Higher weights make a feature more influential when determining which Pokémon is considered more desirable.

* **Type**: `object`

#### shiny

Weight assigned to shiny Pokémon.

* **Type**: `float`
* **Default**: `10.0`

#### perfectIvsRates

Defines the weight assigned to Pokémon based on the number of perfect IVs they have.

The keys represent the number of perfect IVs, from `1` to `6`.

* **Type**: `object`

| Perfect IVs | Default |
| ----------: | ------: |
|           1 |   `1.0` |
|           2 |   `2.0` |
|           3 |   `3.0` |
|           4 |   `4.0` |
|           5 |   `5.0` |
|           6 |   `6.0` |

#### hiddenAbility

Weight assigned to Pokémon with a hidden ability.

* **Type**: `float`
* **Default**: `1.0`

#### eggMove

Weight assigned to Pokémon with an egg move.

* **Type**: `float`
* **Default**: `1.0`

### collectableConditions

Determines which spawn condition collectors are enabled. Disabled collectors will not contribute their respective conditions to Pokémon information.

* **Type**: `object`

## Client Configuration

```json title="config/cobblenav/client-config.json"
{
  "screenScale": 1.0,
  "enableBlurEffect": true,
  "sendErrorMessagesToChat": true,
  "pokefinderScreenScale": 1.0,
  "pokefinderOverlayScale": 1.0,
  "pokefinderOverlayOffsetX": 10,
  "pokefinderOverlayOffsetY": 10,
  "enableDisplayOfNamesOnRadar": false,
  "trackArrowYOffset": 80,
  "maxCloudNumber": 8,
  "maxCloudVelocity": 6,
  "enableItemShaking": true,
  "enableMultipleModelItems": true
}
```

### screenScale

Multiplier for the scale of the CobbleNav user interface.

* **Type**: `float`
* **Default**: `1.0`

### enableBlurEffect

Determines whether blur effects are used in CobbleNav interfaces. Disable this if you experience visual glitches caused by mod conflicts.

* **Type**: `boolean`
* **Default**: `true`

### sendErrorMessagesToChat

Determines whether errors encountered while loading animation models are displayed in the in-game chat.

* **Type**: `boolean`
* **Default**: `true`

### pokefinderScreenScale

Multiplier for the scale of the PokéFinder screen.

* **Type**: `float`
* **Default**: `1.0`

### pokefinderOverlayScale

Multiplier for the scale of the PokéFinder overlay.

* **Type**: `float`
* **Default**: `1.0`

### pokefinderOverlayOffsetX

Horizontal offset of the PokéFinder overlay from the edge of the screen.

* **Type**: `integer`
* **Default**: `10`

### pokefinderOverlayOffsetY

Vertical offset of the PokéFinder overlay from the edge of the screen.

* **Type**: `integer`
* **Default**: `10`

### enableDisplayOfNamesOnRadar

Determines whether Pokémon names are displayed above Pokémon detected by the radar.

* **Type**: `boolean`
* **Default**: `false`

### trackArrowYOffset

Vertical offset of the tracking arrow from the bottom of the screen.

* **Type**: `integer`
* **Default**: `80`

### maxCloudNumber

Maximum number of clouds that can be displayed on the FishingNav screen.

* **Type**: `integer`
* **Default**: `8`

### maxCloudVelocity

Maximum velocity of clouds displayed on the FishingNav screen.

* **Type**: `integer`
* **Default**: `6`

### enableItemShaking

Determines whether items can use the item-shaking animation.

* **Type**: `boolean`
* **Default**: `true`

### enableMultipleModelItems

Determines whether items that support multiple models can use those models.

* **Type**: `boolean`
* **Default**: `true`
